# Project-06: 3D House Finder RPG

## Features added
- **Third-person controller**  
  - FREE Low Poly Human – RPG Character (with Mixamo walk/run/idle animations)  
  - Keyboard + mouse movement, Cinemachine camera follow & smoothed rotation  
- **Interactive world**  
  - RPG Poly Pack - Lite environment assets (terrain meshes, rocks, props)  
  - Mesh-based “doors” with transparent trigger volumes  
- **Dialogue system**  
  - Ink integration for branching conversation at each door  
  - Dynamic yes/no choice buttons generated at runtime  
- **Visual clues & logic**  
  - Six “clues” (yellow flower, stone, barrel, vase, sack of grain, coat rack)  
  - Randomly assign one correct house, ensure no wrong house ever shows the true clue  
- **Scoring & win/lose**  
  - Track up to 3 wrong answers in UI (“0/3” → “3/3”)  
  - “Game Over” screen on 3 wrong answers  
  - “Victory” screen when the one correct door is answered “Yes”  
- **UI & UX polish**  
  - Intro instructions panel with “Start” button  
  - Dialogue panel with TextMeshProUGUI text and choice buttons  
  - Win/Game Over panel with restart button
